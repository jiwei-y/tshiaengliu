## 二、語體分層詞彙庫

### 1. 四六駢文高頻雅詞與偶語

- **常用雙音雅詞**：覆載、照臨、宸聰、殊恩、微效、殫竭、屏營、兢越、丹款、令圖、盛事、休咎、幽明、華夏、社稷、神祇、器能、任使、恩澤、綱紀、股肱、爪牙、羽翼、聲教。
- **典型對舉偶語**：覆載 ↔ 照臨、天高 ↔ 日遠、內防 ↔ 外扞、幽明 ↔ 華夏、器能 ↔ 任使、微效 ↔ 殊恩、賞罰 ↔ 勸懲、盡瘁 ↔ 無偏。

### 2. 駢散兼行高頻論辯詞與虛詞

- **論辯骨幹詞**：所以、以為、可以、是以、不足、不可、不能、不得、所謂、之道、之心、之意、利害、事體、機便、輕重、緩急、本末。
- **起承轉合虛詞**：
  - 領起總提：`夫`、`臣聞`、`蓋`、`原夫`、`若乃`、`今者`、`頃者`、`比者`
  - 因果推論：`故`、`是以`、`然則`、`良以`、`豈不以`
  - 讓步假設：`雖`、`苟`、`儻`、`縱`、`况`、`設使`、`假令`
  - 反詰層進：`豈唯`、`豈徒`、`非止`、`何則`、`不亦……乎`、`抑又聞之`

### 4. 稱謂與起訖套語

語料中按語體繁簡呈現如下稱謂與起訖套語：

- **自稱**：`臣`、`微臣`、`臣某`（短密狀常省主語，直陳事由）。
- **尊稱**：`陛下`、`聖恩`、`宸聰`、`聖旨`、`進止`。
- **起手與承轉**：
  - 四六駢文：`臣某言`、`右臣伏以`、`伏惟陛下`、`臣聞`、`伏乞聖恩`。
  - 駢散兼行：`右臣聞`、`竊見`、`竊聞`、`伏見`、`願陛下`。
  - 中古口語公牘：`右，臣商量`、`臣伏見`、`如蒙允許`、`望付……處分`。
- **收尾**：
  - 四六駢文：`干冒宸嚴，無任屏營戰越之至`、`誠歡誠喜，頓首頓首，謹言`、`謹奉表以聞`、`謹錄奏聞，伏聽敕旨`。
  - 駢散兼行：`不勝管窺願效之至，謹陳冒以聞。謹奏`、`謹錄奏聞，伏聽進止`。
  - 中古口語公牘：`未審可否`、`未審`、`謹奏`、`如蒙允許，望賜處分`。

## 三、句式、節律與對仗

### 1. 分句字數分布（實測占比）

| 語體 | 2字 | 3字 | **4字** | 5字 | **6字** | 7字 | 8字 | ≥9字（長散句） | 四六句合計 |
| - | - | - | - | - | - | - | - | - | - |
| **四六駢文** | 2.0% | 2.7% | **46.0%** | 9.6% | **20.4%** | 9.4% | 4.4% | 4.3% | **66.4%** |
| **駢散兼行** | 3.0% | 3.0% | **41.4%** | 10.8% | **18.4%** | 10.3% | 5.2% | 6.6% | **59.8%** |
| **中古口語公牘** | 3.4% | 2.4% | **35.9%** | 11.3% | **17.8%** | 8.8% | 6.7% | **10.4%** | **53.6%** |

### 2. 四六隔句與句末虛詞分工

- **相鄰四六轉移**：三語體均以 `4-4` 居首（四六文 1,537 次），其次 `6-4`（587）與 `4-6`（570），再其次 `6-6`（406）。四六文以四四起調定韻、四六／六四隔對鋪陳；駢散兼行以散句引領、偶句對比；中古口語公牘不求對仗，遇事實細節自然拉長至 8–15 字散句。
- **句末語氣虛詞**：
  - **四六駢文**：少用句末虛詞，多以實詞偶語收煞。
  - **駢散兼行**：虛詞極豐——`也`（判斷定調）、`矣`（已然／必然之斷）、`焉`（歸結）、`乎`（設問反詰）、`哉`（感嘆反問）、`耳`（限定收束）、`歟`（婉轉推問）。
  - **中古口語公牘**：幾乎不用文言句末虛詞，語氣乾脆利落。

## 四、用典特徵（四六文專項）

1. **句格與密度**：於鋪陳、讚譽、陳情處以四字一典（如「成湯祝網」「大禹泣辜」）或六字含一典（如「惜漢氏十家之產，復周邦九歲之儲」），上下聯成事對。
2. **用典三法**：
   - **正用事對**：取 `allusions/chuxueji_shidui.csv` 雙典並舉成對（如 `【分陰　寸晷】` → 「常懷陶侃惜陰之志，敢忘潘尼寸晷之勤」）。
   - **反用自謙**：以典故自照而謙言不及（如李商隱「聽金石而慚殊舞獸，無羽翼而恨異冥鴻」）。
   - **化用入語**：提煉典中雙字融入四字句（如 `【儀表　珪璋】` → 「器宇珪璋，群倫儀表」）。
3. **典故核驗**：凡輸出四六文，必須優先檢索 `allusions/chuxueji_shidui.csv`，輔以 `allusions/chuxueji_allusion.csv`，核對 `source_text` 後入句，嚴禁杜撰。
