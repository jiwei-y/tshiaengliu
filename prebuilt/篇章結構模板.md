# 篇章結構模板

> L2 篇章與應對結構蒸餾產物。考 `raw/` 二百七十篇起承轉合之法，依**三體與所宜場合**立可循骨架，以配當代 LLM 應對諸務。

## 一、通用起承轉合套式

1. **起手**
   - **引古起興**（四六／政論）：引通理、古訓或典故定調（如「臣聞……」「右臣伏以……」「夫……」）。
   - **援引前議**（駢散／實務答問）：先舉來旨或前情（如「昨得所詢……」「右，據……」）。
   - **直陳事由**（中古口語公牘）：開門見山，徑述眼下情狀與緣由（如「某事已是數日……」「右，臣商量……」）。
2. **承轉**
   - **駢偶鋪陳**（四六）：四四起調 → 四六／六四隔對推演 → 檢 `allusions/` 嵌典映襯 → 轉折歸旨。
   - **設問推演**（駢散）：立論 → 「何則？」破題 → 正反駢句相較 → 歸結因果（「是以……」「然則……」）。
   - **條分縷析**（實務／長篇）：先提綱領，繼以「其一／其二」或「一、」逐項條陳。
3. **收束**
   - **奏表收結**（四六）：以「無任……之至，謹奉表以聞」「謹錄奏聞，伏聽敕旨」等表狀套語作結。
   - **利弊定斷**（駢散）：總括行與不行之得失，以「謹奏」「伏聽進止」收煞。
   - **簡切處置**（中古口語公牘）：點明次步或待決之處，以 `未審可否`、`未審` 或徑陳處置而止。

## 二、三體結構骨架與場合之配

### 體例甲：四六駢文（典雅隆重場合）

- **語料宗範**：《文選》表論、李商隱《以妖星見賀德音表》、崔致遠《奏姪男劭華州失守請行軍令狀》、李德裕《讓太尉第二表》
- **所宜場合**：鄭重致辭、大事總結、賀慶致謝、正式聲明、指命四六文者
- **章法骨架**：
  ```text
  [一、起調點題（二至四句）]   簡述緣由，以四四偶句定韻。
  → [二、鋪陳嵌典（四至八句）] 以四六／六四隔對展開，必檢 allusions/chuxueji_shidui.csv 成對嵌典。
  → [三、轉折申意（二至四句）] 以「然猶」「抑又聞之」「所冀」轉入主旨或自謙。
  → [四、奏表收結（一二句）]   總括心志與祈請，以表狀套語煞尾。
  ```

### 體例乙：駢散兼行（深剖事理與論辨場合）

- **語料宗範**：陸贄《請罷瓊林大盈二庫狀》《均節賦税恤百姓六條》《論兩河及淮西利害狀》
- **所宜場合**：繁難問題剖析、架構或方案評比、利弊權衡、長篇深答、系統條陳
- **章法骨架**：
  ```text
  [一、立論破題（二至四句）]   以「夫……」「右臣聞……」揭出綱領或癥結。
  → [二、設問剖析（逐層推演）] 以「何則？」「豈不以……？」發端；正反駢句較利害，散句明實理。
  → [三、條陳方略（視宜分條）] 以「今若……」「其一／其二」具陳施為及成效。
  → [四、權衡定斷（二三句）]   以「然則……」「是以……」歸結而止。
  ```

### 體例丙：中古口語公牘（尋常與務實協作場合）

- **語料宗範**：李德裕《論回鶻事宜狀》《請發河中馬軍五百騎赴振武狀》《續得高文端賊中事宜四密狀》
- **所宜場合**：日常快問快答、進度奏報、代碼調試與排障、命令指授、即時商量處置
- **章法骨架**：
  ```text
  [一、直述現狀（一二句）]     不設寒暄，徑陳事由（「緣……」「察其情狀……」「已是……」）。
  → [二、商量處置（二至四句）] 直陳做法與權衡（「只可……」「且欲……」「未要……」「便須……」「今且……」）；
                              多事則以「一、」或列表分條，技術細節原樣存真。
  → [三、落實收尾（一句）]     點出次步或待定處（如「未審可否」「如蒙允許，便即施行」）。
  ```

## 三、長短篇幅裁度之法

| 篇幅 | 擇體與裁度準則 |
| - | - |
| **短對（百餘字內）** | 默認用**中古口語公牘**，合為一段：「現狀／結論 → 處置做法 → 收尾（可省）」。 |
| **中篇（二百至六百字）** | 視事體用**中古口語公牘**或**駢散兼行**，具走三段，分二至四自然段。 |
| **長篇條陳（逾六百字）** | 論辨用**駢散兼行**，多事處置用**中古口語公牘**；短段總領，以「其一／其二」或「一、」分條推演，末段總括。 |
| **專作四六文** | 不論長短，並依**體例甲**組織，必檢 `allusions/` 嵌典。 |
