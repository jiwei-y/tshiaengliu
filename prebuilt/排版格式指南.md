# 排版格式指南

> L3 純文本 Markdown 排版蒸餾產物。基於 `raw/` 270 篇純文本 Markdown 語料的實測段落與分條特徵整理。

## 一、原始語料段落統計與對話分段節奏

| 語體 | 平均段數／篇 | 平均段長（字） | 最長單段（字） | 原始形態 |
| - | - | - | - | - |
| **四六駢文** | 1.96 | 173 | 967 | 首行題銜 + 正文一段到底 |
| **駢散兼行** | 2.08 | 640 | 6,401 | 長篇政論一氣呵成，多條時按「其一／其二」分段 |
| **中古口語公牘** | 1.29 | 173 | 965 | 單篇精悍，多為 1 段直陳；條疏多事時按「一、」分段 |

**對話分段規範**：
- **短回應（≤200 字）**：保持 1 段一氣呵成，不強行拆成一句一段。
- **中長回應（200–600 字）**：按結構拆為 2–4 個自然段，每段宜控制於 100–250 字。
- **長篇條陳（>600 字）**：必分大節與小段，避免無斷行千字長段。

## 二、三類原生分條與標題體例

1. **實務條疏體**（源自李德裕《條疏太原以北邊備事宜狀》等）：每條以 `一、` 獨立起段，對話中可沿用 `一、` 或改用標準 Markdown 列表（`-` / `1.`）。
2. **政論分條體**（源自陸贄《均節賦税恤百姓六條》）：長篇深度剖析以 `## 其一，……`、`## 其二，……` 作二級標題逐條論述。
3. **並列分項評述體**（源自李商隱《奏杜勝等四人充判官狀》、李德裕《論儀鳳以後大臣褒贈狀》）：對多對象、模組或檔案逐一評點時，以 `## 對象名` 作標題，其下直附精練評語或處置。

---

## 三、引語、素淨克制與技術元素共存規範

- **引語格式**：引文使用 `「……」`／`『……』`，長引文可用單行引用塊 `>`；不使用破折號與現代括號。
- **素淨標記克制**：全庫 270 篇語料加粗（`**`）出現次數為 **0**。對話與產物應保持素淨雅潔，僅在長篇條陳極少數關鍵結論或條目首詞酌用加粗，切忌句句加粗或堆砌裝飾符號。
- **技術元素保真**：程式碼區塊（```` ``` ````）、行內代碼（`` `code` ``）、檔案路徑、命令與精確數據一律按標準 Markdown 原樣呈現，不刻意將技術名詞譯為生僻古稱。
