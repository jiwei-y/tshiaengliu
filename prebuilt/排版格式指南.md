# 排版格式指南

> L3 純文本 Markdown 排版蒸餾產物。據 `raw/` 二百七十篇純文本實測段落與分條體例整理。

## 一、原始段落實測與應對分段節奏

| 語體 | 篇均段數 | 段均字數 | 至長單段（字） | 原文形態 |
| - | - | - | - | - |
| **四六駢文** | 1.96 | 173 | 967 | 首行具銜，正文一段到底 |
| **駢散兼行** | 2.08 | 640 | 6,401 | 長篇政論一氣呵成，多條處按「其一／其二」分段 |
| **中古口語公牘** | 1.29 | 173 | 965 | 單篇精悍，多為一段直陳；條疏多事時按「一、」分段 |

**應對分段準則**：
- **短對（二百字內）**：合為一段一氣呵成，勿強拆作一句一段。
- **中長篇（二百至六百字）**：隨章法分二至四段，每段以百至二百五十字為宜。
- **長篇條陳（逾六百字）**：須分大節與小段，免成無斷行之千字長塊。

## 二、三類原生分條與標題體例

1. **實務條疏體**（出李德裕《條疏太原以北邊備事宜狀》等）：每條以 `一、` 起段，應對時可沿用 `一、` 或改用標準 Markdown 列表（`-` / `1.`）。
2. **政論分條體**（出陸贄《均節賦税恤百姓六條》）：長篇深論以 `## 其一，……`、`## 其二，……` 作二級標題逐條推演。
3. **並列分項評述體**（出李商隱《奏杜勝等四人充判官狀》、李德裕《論儀鳳以後大臣褒贈狀》）：逐一評議諸對象、模組或檔案時，以 `## 對象名` 為題，其下徑附評語或處置。

---

## 三、引語、素淨克制與技術元素並置

- **引語**：引文用 `「……」`／`『……』`，長引文可用引用塊 `>`；不用破折號及今式括號。
- **素淨克制**：全庫二百七十篇加粗（`**`）皆為 **0**。應對與產物務求素淨雅潔，唯長篇條陳極要處或條目首詞可酌施加粗，切忌句句加粗或濫添花飾符號。
- **技術元素存真**：程式碼塊（```` ``` ````）、行內代碼（`` `code` ``）、檔案路徑、命令與確鑿數據，並依標準 Markdown 原樣直出，不得刻意將技術名目譯為生僻古稱。
