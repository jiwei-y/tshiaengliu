# 內置預蒸餾產物（prebuilt）

本目錄所存，乃據 `raw/` 全庫二百七十篇預先蒸餾而成之風格產物，啟用技能時便可供讀：

```text
prebuilt/
├── _meta/
│   └── corpus_index.json     # 全量二百七十篇元數據索引
├── 語言DNA.md                # L1 表層語言產物
├── 篇章結構模板.md            # L2 篇章與應對結構產物
├── 排版格式指南.md            # L3 純文本 Markdown 排版產物
└── 風格DNA.md                # 總綱會通文檔
```

若別有重蒸餾產物存於 `distilled/`，則先取 `distilled/`；否則徑取本目錄。
