# 清流話風（tshiaengliu）

將本倉庫 `raw/` 目錄中的唐代與六朝名篇（四六駢文、文言散文、中古漢語口語公牘）蒸餾為可執行的風格 DNA，並結合 `allusions/`《初學記》典故庫，賦予 LLM agent 與 LLM chatbot 古雅而分層得體的**對話語言**與**默認產物語言**。

## 核心特點

- **直接用於對話**：蒸餾產物直接約束 LLM agent／chatbot 與用戶互動時的遣詞、句律與章法。
- **產物語言默認一致**：除非用戶額外指定（例如要求某份文檔改用現代白話或英文），模型生成的報告、總結、說明等產物，其語言風格默認與對話語言相同。
- **內置語料，統一蒸餾**：以本倉庫 `raw/` 目錄下的全部文獻（共 270 篇）合併蒸餾為一套統一的風格產物，並按**用途與場合**區分語體層級。
- **四六文必用典故庫**：凡輸出四六文時，模型必須檢索並運用 `allusions/` 目錄中的《初學記》典故與事對，確保對仗工整、用事有據。
- **只取文字，不取思維**：專注於蒸餾古人的文字氣韻、結構章法與純文本排版；現代知識與問題解決邏輯仍由 LLM 自身承擔。

## 內置語料與語體分層

`raw/` 目錄收錄五組風格鮮明、用途各異的純文本 Markdown 文獻：

| 目錄 | 篇數 | 代表體裁與語體特徵 | 對應 LLM 對話場合 |
| - | - | - | - |
| `raw/文選/` | 14 | 六朝表、論，詞藻典麗，駢文典範 | 鄭重致辭、隆重論述、典雅四六文 |
| `raw/李商隱/` | 28 | 晚唐四六表狀，對仗精工、用典極密 | 正式賀慶、典雅總結、四六駢文 |
| `raw/崔致遠/` | 36 | 晚唐四六奏狀，駢儷工穩、公文格式嚴整 | 正式陳情、規範匯報、四六駢文 |
| `raw/陸贄/` | 56 | 中唐政論奏議，駢散兼行、條理縝密 | 深度分析、方案論證、利弊權衡 |
| `raw/李德裕/` | 136 | 兼含典雅讓表與大量邊防密狀，富含**中古漢語口語與唐代實務公牘** | 日常問答、即時匯報、工程排障等務實對話 |

蒸餾時將上述五組語料合併為一套統一的風格產物，並在其中區分三大語體層級：

1. **四六駢文**（典雅隆重場合，配合 `allusions/` 用典）
2. **駢散兼行**（深度分析與條陳論辯場合）
3. **中古口語公牘**（日常對話與務實協作場合）

## 內置典故庫（`allusions/`）

`allusions/` 目錄提供整理自《初學記》的兩份 CSV 數據表：

- `allusions/chuxueji_shidui.csv`（3,564 組對偶事對）：提供成對典故及雙方出處原文（如 `【轉蓋　倚杵】`、`【覆盆　轉轂】`），專供四六文駢句對仗檢索。
- `allusions/chuxueji_allusion.csv`（7,128 條單典）：提供單條典故名與出處原文，供單句嵌典與典意核驗。

## 蒸餾層次

| 層次 | 分析對象 | 產物文件 |
| - | - | - |
| **L1 表層語言** | 三大語體詞彙（雅詞、文言虛詞、中古口語詞）、四六節律與對仗、聲律語氣、用典特徵、古文斷句標點 | `語言DNA.md` |
| **L2 篇章結構** | 起承轉合套式、按用途／場合分層的三大語體結構模板、古文體裁至現代對話場合的映射 | `篇章結構模板.md` |
| **L3 排版格式** | 純文本 Markdown 的段落節奏、分條層級與引用規範 | `排版格式指南.md` |

最終整合為總入口文檔 `風格DNA.md`，連同 `distilled/_meta/` 元數據索引一併輸出。

## 快速上手

### 1. 執行蒸餾

讓 agent 完整閱讀 [`SKILL.md`](SKILL.md)，對本倉庫 `raw/` 目錄執行蒸餾：

```text
請閱讀 SKILL.md，依其中的流程與模板，對本倉庫 raw/ 目錄下的全部文檔執行蒸餾，並將產物輸出至 distilled/ 目錄。
```

### 2. 在對話中啟用風格

完成蒸餾後（或直接採用 `examples/format-only/` 中的參考產物），在對話開始前讓 agent 載入蒸餾產物並抽讀 `raw/` 原文校準語感：

```text
請先閱讀 distilled/（或 examples/format-only/）下的全部風格產物（風格DNA.md、語言DNA.md、篇章結構模板.md、排版格式指南.md），再依 _meta/corpus_index.json 從 raw/ 抽讀 5 篇代表原文校準語感。之後以此作為與我對話及默認產物的語言風格；遇日常事務用中古口語公牘，遇深度剖析用駢散兼行，遇鄭重致辭或我指定四六文時則檢索 allusions/ 中的典故與事對作答。
```
