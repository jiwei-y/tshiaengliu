# 蒸餾產物體式（templates）

本目錄所列，乃對 `raw/` 重行蒸餾時所依之文書體式。施行蒸餾時，並依下式輸出至倉庫根目錄 `distilled/`：

```text
distilled/
├── _meta/
│   └── corpus_index.json     # 全量元數據索引（體式見 _meta/example.schema.json）
├── 語言DNA.md                # L1 表層語言產物
├── 篇章結構模板.md            # L2 篇章與應對結構產物
├── 排版格式指南.md            # L3 純文本 Markdown 排版產物
└── 風格DNA.md                # 總綱會通文檔
```
