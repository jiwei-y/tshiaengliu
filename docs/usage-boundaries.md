# 使用邊界

`tshiaengliu`（清流話風）用於將本倉庫內置的歷代古籍語料（`raw/`）與《初學記》典故庫（`allusions/`）轉化為 LLM agent 與 chatbot 的對話語言及默認產物語言。

請注意：

- **只取文字，不取思維**：本項目僅復刻古人的文字表達、語體層級、句法節律、章法結構與用典習慣，不代表亦不應模仿古人的時代觀念、價值立場或思維方式。
- **事實與技術保真**：在工程、學術、程式碼與事實問答中，不得為了追求古雅或對仗而竄改技術細節、程式碼、路徑、數據或結論。
- **杜絕生造假典**：輸出四六文時應查驗 `allusions/` 中的出處原文（`source_text1`／`source_text2`），不得憑空捏造典故。
- **尊重用戶指令**：產物語言默認與對話語言一致，但當用戶明確指定改用現代漢語、英文或其他規格格式時，須優先服從用戶要求。
- **語料權屬**：本倉庫 `raw/` 與 `allusions/` 均為公有領域古籍文獻；若向倉庫新增外部語料，請確保無版權爭議。
