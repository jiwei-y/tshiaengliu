# 韓琮

右件官早中殊科，素推雅度。弦柔以直，濟伏而清。頃佐憲臺，且丁家難。當喪而齒未嘗見，既琴祥而琴不成聲。逮此變除，未蒙抽擢。臣頃居鎮守，琮己列賓僚。謀之既臧，剛亦不吐。𩓑稽中選，榮借外藩。伏請依資賜授憲官，充臣莭度判官。

# 叚環

右件官言思無邪，學就有道。屢爲從事，常佐正人。加以富有文詞，精干草隸，雋而且簡，襝通“亦”不流。臣所部稍遠京都，每繁章奏，敢兹上請，乞以自隨。伏請依資賜授憲官，充臣莭度掌書記。

# 裴蘧

右件官魯國名儒，𨛬鄉右族。松寒更翠，馬老不迷。臣昔忝鑿門，辟爲記室。屬辭而夙搆無異，論兵而故校多歸。畫以前籌，見其餘地。前任大理評事已三十三個月。比于流輩，已是滯淹。伏請特授憲官，充臣觀察支使。

# 夏侯曈

右件官，藏器于身，爲人由己。齊莊難犯，勁挺不揺。臣任切循良，務繁稽勾。留思仙尉，以重賓階。伏請依資改授一官，充臣莭度巡官。

以前件狀如前。臣四朝受任，三鎮叨榮。慕碣石之築宫，廣延儒雅；效西河之擁篲，樂得賢才。韓琮等並無所因依，不由請托。久諳才地，堪列幕庭。伏希殊私，盡允誠請。謀録奏聞，伏聽敕㫖。
