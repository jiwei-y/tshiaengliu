# 杜勝

右件官，流慶相門，策名“詞苑”。當仁罕譲，見義敢爲。符彩極高，涯涘難挹。臣前任己奏爲判官，臨事而每見公方，與語而必相弘益。今臣既分團練，任切訓齊。將奉廟謨，實在賓彦。伏請賜守本官，充臣團練判官。

# 趙晰

右件官，洛下名生，山東茂族。仁實甚富，天爵極高。妙選文場，亟仕侯國。珪璋特逹，蘭社芬馨。今臣廉問大藩，澄清列部，藉其謨畫，共贊朝經。伏請賜守本官，充臣觀察判官。

# 李藩

右件官，文囿馳聲，賓階擅美。口含言瑞，身出禮門。前任已奏爲判官，馭下而和易不流，臨事而貞方有執。今臣移參國用，務切軍須，實假平均，以同計畫。伏請賜本官，充臣觀察支使。

# 盧涇

右件官，傳涉典經，該覈流略。自魯壁所壞，汲冢之藏，三篋能知，五車盡究。加之文彩，兼以器能。前者爲屬臣僚，常在州推獄。明斷而不容吏黠，哀矜而莫有人冤。今者團練之司，稽巡事切，每思奬敕，非敢用情。伏請依資賜授法官，充臣都團練巡官。

以前件狀如狀。伏以長人者，必以吏分勞逸；開幕者，亦用士爲重輕。若不樹人，何以報國？况臣素無勛效，謬竊𠖥榮。至于賢才，敢　恡筐篚。前件官，並推賓彦，堪贊藩條。伏希殊私，盡允誠請。謹録奏聞，伏聽敕㫖。
